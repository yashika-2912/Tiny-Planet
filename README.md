# Tiny Planet

AI-powered intelligent travel planning platform built with a MERN-style architecture and free-tier friendly integrations.

## Apps

- `client` - Vite + React travel planning interface
- `server` - Express API with MongoDB, JWT auth, Gemini itinerary/chat, OpenTripMap-ready hotel search, and route/budget utilities

## Quick Start

```bash
npm install
npm run dev
```

Client: `http://localhost:5173`  
Server: `http://localhost:5000`

Copy `server/.env.example` to `server/.env` and fill values for production integrations.
